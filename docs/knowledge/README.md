# Account Researcher Portal - knowledge base

## What this is

Working knowledge exported from Claude before that tooling was retired. It is **context, not code** - nothing here runs.

## How to use it

Read `AGENTS.md` at the repo root first. This folder keeps the repo-local as-built docs; the full Account Researcher transcript set lives in the pipeline repo at [`../../../prospect-research/docs/knowledge`](../../../prospect-research/docs/knowledge).

## Layout

| Path | What |
|---|---|
| `AS-BUILT.md` | Current-state spec across all three Account Researcher repos. |
| `NOTION-INDEX.md` | Verified Notion page IDs and Notion handling rules. |
| `sessions/INDEX.md` | Pointer to the canonical Account Researcher transcript index in `~/M4S/prospect-research`. |

The fuller set - distilled sessions, quality baseline, exported memory notes, and full transcripts - lives in `~/M4S/prospect-research/docs/knowledge/`.
